# TomeVault Skills Registry

Reusable AI instruction files in `SKILL.md` format, graded against the public Tome Standard and kept true across platforms by [TomeVault](https://tomevault.io), indexed by [Skills.sh](https://skills.sh) and [SkillsMP](https://skillsmp.com).

## Install

Each skill lives in its own subdirectory with a `SKILL.md` and a per-skill README. Copy a skill into your project's `.claude/skills/` (or equivalent) directory.

## Browse

Search, filter, and discover skills across every platform at [tomevault.io](https://tomevault.io).

---

> Every package links its original creator. Graded against the public [Tome Standard](https://tomevault.io/standards) and kept in sync across platforms by [TomeVault](https://tomevault.io). TomeVault watches AI instruction files for silent drift on every push and every model release, and signs the verdict.
